
# Описание
Портативный редактор файлов локализации *.lcache* для Gothic 1 Remake. Инструмент создан для замены ручного редактирования в hex-редакторах. Программа работает с файлом напрямую в оперативной памяти (In-Memory), обрабатывая внутреннюю структуру формата.

# Установка
Установка не требуется. Программа полностью портативна, достаточно запустить исполняемый файл.

# Основные возможности
* **Полный парсинг и сборка .lcache:** Работает с нативной структурой файла с применением корректного внутреннего AES-шифрования.
* **Рабочее пространство «Дерево диалогов»:** Интерактивное отображение иерахии, которое преобразует плоские строки перевода в структурированные цепочки диалогов.
* **Автоматическое управление кодировкой:** Автоматически переключается на UTF-16LE при обнаружении любых символов не из таблицы ASCII (кириллица, умлауты) для предотвращения поломки шрифтов. Строки только с латиницей сохраняются в компактном UTF-8.
* **Автосинхронизация переводов:** Обновление перевода автоматически меняет текст во всех связанных дубликатах ключей с суффиксами (_new, _newer, _v3, _v2, _patch).
* **История действий:** Централизованный менеджер отмены и повтора действий (Ctrl+Z / Ctrl+Y).
* **Поиск и фильтрация:** Полнотекстовый поиск и быстрые фильтры для изоляции или скрытия конкретных строк.
* **Локализация интерфейса:** Интерфейс редактора можно полностью переключить на английский, русский, польский, немецкий, французский или испанский язык кнопкой на панели инструментов.
* **Сохранение настроек (settings.ini):** Запоминает выбранную тему (включая темный и теплый режимы), параметры разметки и ширину столбцов.
* **Индикация статуса:** Отображает общее количество ключей, процент завершения перевода и отслеживает несохраненные изменения.

# Что программа НЕ МОЖЕТ (и не будет) делать:
* Добавлять новые текстовые ключи или внедрять в файл совершенно новые языки.
* Работать с другими играми, кроме Gothic 1 Remake.
* Исправлять ошибки в коде от разработчиков игры.
* Предотвращать случайную порчу собственного текста или опечатки.
* Служить примером идеального кода.

# Требования
* **Операционная система:** Windows 10 / Windows 11 (64-bit) или Linux (64-bit дистрибутивы через Proton/Wine).
* Не требует установки Python или сторонних библиотек.
* Поддерживает пути к файлам, содержащие кириллицу и пробелы.
* При сохранении старый файл автоматически переименовывается в *.bak* для предотвращения потери данных.
* Ошибки и сбои приложения записываются в файл *error_log.txt* рядом с исполняемым файлом.
