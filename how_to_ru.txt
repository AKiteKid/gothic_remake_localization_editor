# Руководство по сборке и запуску

## Установка или обновление Python

Для работы редактора необходим Python версии 3.9 или новее (актуальная версия — 3.14.7). Если у вас установлен более старый Python (3.8, 3.7 и ниже), программа выдаст ошибку и не запустится.

1. Перейдите на официальный сайт: https://python.org и нажмите на большую жёлтую кнопку **Download Python**.
2. Выполните установку для вашей операционной системы:
   * **Windows**: Запустите скачанный файл. Если Python уже был, нажмите **Upgrade Now**; если ставите с нуля — **Install Now**. *Критически важно*: в самом первом окне внизу обязательно поставьте галочку **Add Python to PATH**. Дождитесь окончания установки.
   * **macOS**: Запустите файл `.pkg`. Он установит новую версию рядом со старой. Чтобы система её увидела, в терминале используйте команду `python3`.
   * **Linux**: Обновите пакеты через терминал:
     
     sudo apt update && sudo apt install python3 python3-pip

3. После установки проверьте версию, открыв командную строку (Windows) или терминал (macOS/Linux) и введя:
   
   python --version
   
   Если команда не работает, попробуйте `python3 --version`. Если на экране появилось `Python 3.9.x` или выше — всё готово к работе.

## Открытие терминала в папке с проектом

Убедитесь, что вы находитесь именно в корневой папке проекта — той, внутри которой лежит файл `main.py`. Иногда архиваторы при распаковке создают структуру «папка в папке», поэтому проверьте, что вы сразу видите `main.py`.

* **Windows (способ А — быстрый)**: Откройте папку проекта (где лежит `main.py`), кликните мышкой по адресной строке вверху окна, сотрите весь текст, введите `cmd` и нажмите **Enter**. Откроется чёрное окно консоли.
* **Windows (способ Б — альтернативный)**: Откройте папку проекта, зажмите клавишу **Shift** и кликните правой кнопкой мыши по пустому месту внутри папки, выберите пункт **«Открыть окно PowerShell здесь»** или **«Открыть в терминале»**.
* **macOS / Linux**: Откройте Терминал, введите `cd ` (с пробелом после), затем перетащите папку проекта (где лежит `main.py`) из Finder/проводника прямо в окно Терминала и нажмите **Enter**.

## Установка библиотек

В открывшемся терминале введите команду и нажмите **Enter**:

    pip install PyQt6 pycryptodome

Если появляется ошибка `pip: command not found`, используйте:

    python -m pip install PyQt6 pycryptodome

*(На macOS/Linux вместо python пишите python3)*. Дождитесь сообщения об успешной установке библиотек.

## Запуск редактора

В том же терминале выполните:

    python main.py

*(На macOS/Linux: `python3 main.py`)*. Появится окно программы.

Если при старте программа попросит JSON-файлы, укажите ей на папку `json`, которая лежит внутри проекта. Затем нажмите кнопку **Import**, выберите ваш файл `.lcache` и приступайте к редактированию.

## Создание исполняемого файла (.exe)

Если вы хотите запускать редактор без терминала или передать его другу, у которого нет Python, можно собрать автономное приложение.

1. В терминале папки установите сборщик:
   
   pip install pyinstaller

2. Запустите команду сборки для вашей ОС:
   * **Для Windows**:
     
     pyinstaller --onefile --windowed --add-data "core;core" --add-data "modules;modules" --add-data "json;json" --name "GothicEditor" main.py
     
   * **Для macOS / Linux** (вместо `;` используется `:`):
     
     pyinstaller --onefile --windowed --add-data "core:core" --add-data "modules:modules" --add-data "json:json" --name "GothicEditor" main.py

Через пару минут в папке проекта появится папка `dist`, внутри которой будет готовый файл `GothicEditor.exe` (или приложение для Mac). Его можно переносить куда угодно — он работает самостоятельно.

## Решение проблем

| Проблема | Решение |
|----------|---------|
| `ModuleNotFoundError: No module named 'Crypto'` | Заново выполните `pip install pycryptodome`. |
| `ModuleNotFoundError: No module named 'PyQt6'` | Повторите `pip install PyQt6`. |
| Ошибка про `dialog_context_plugin` | Вы случайно перенесли или удалили папку `modules`. Она обязательно должна лежать в одной папке рядом с `main.py`. |
| Таблица в редакторе пустая | Программа не открывает файлы автоматически при старте. Обязательно нажмите кнопку **Import** и выберите `.lcache`-файл. |
