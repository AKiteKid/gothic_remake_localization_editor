# История изменений

## 0.5
* [Fix] Циклическая рекурсия сигналов интерфейса: Устранен критический сбой, при котором редактирование узла в Дереве диалогов вызывало бесконечный цикл сигналов с главной таблицей. Программное обновление данных теперь безопасно изолировано.
* [Fix] Стабильность навигации по таблице: Исправлен баг с потерей фокуса, когда клик по строке или изменение значений сбрасывали фокус с сетки. Теперь фокус жестко фиксируется на таблице, позволяя быстро перемещаться вниз по ключам с помощью клавиши Tab.
* [Fix] Состояние блокировки исходного текста: Исправлено несоответствие, из-за которого поле исходного текста (Reference) по умолчанию было разблокировано. Иконка замка теперь корректно масштабируется под темную/светлую тему и запускается в безопасном режиме «только для чтение».
* [Fix] Обрезание строки состояния: Устранена ошибка отображения статус-бара приложения путем корректировки фиксированной высоты границ, что полностью предотвращает обрезание текста при операциях с большими файлами.
* [Improvement] Точечный выбор ячеек: Изменено поведение выделения в главной таблице со всей строки на конкретную ячейку. Визуальный фокус теперь заблокирован только на редактируемом элементе, что убирает отвлекающую яркую подсветку строк.
* [Improvement] Сворачивание панелей интерфейса: Переключение на Дерево диалогов теперь автоматически сворачивает нижние поля редактирования (Reference, Target Editor, Metapads), освобождая максимум вертикального пространства для отображения больших цепочек диалогов.
* [Improvement] Многострочные инлайн-редакторы: Инлайн-редактор ячеек таблицы улучшен с однострочного ввода до расширяемого текстового поля. Это полностью сохраняет нативные переносы строк (\n) для длинных нарративных блоков прямо внутри сетки.
* [Improvement] Очистка меню выбора языков: Из интерфейса выбора исходного и целевого языков удалены дубликаты, вызываемые движковыми суффиксами файлов (_newer, _patch, _v3). Теперь отображаются только чистые, читаемые названия языков.
* [Improvement] Унификация темы UI: Исправлены глобальные стили QSS, из-за которых границы вкладок, рамки документов и внутренние панели диалогов сбрасывались до дефолтного серого цвета Windows вместо корректного слияния с теплой светлой темой.
* [Feature] Интерактивное дерево диалогов: Добавлено полноценное рабочее пространство «Дерево диалогов» рядом со стандартной таблицей строк. Система автоматически сопоставляет плоские ключи перевода со сложной структурой диалогов на основе внутренних индексов. Переводчики могут в реальном времени видеть иерархию разговора, ветвление сюжета и контекст реплик.
* [Feature] Динамическое редактирование текста в дереве: Реализовано полное редактирование перевода прямо внутри структуры Дерева диалогов. Изменение реплики персонажа в дереве мгновенно обновляет базу данных, пересчитывает статистику, отмечает изменения и синхронизируется с главной таблицей.

## 0.4a
* [Fix] Устранены прыжки и зеркалирование курсора: Программная вставка текста теперь корректно оборачивается в blockSignals, что полностью устранило сброс каретки, инверсию ввода и зеркальный текст.
* [Fix] Нативная навигация в текстовом поле: Курсор ввода теперь автоматически перемещается в конец текстовой строки при открытии ряда, сохраняя стабильную позицию при активном наборе текста.
* [Fix] Локальный Undo с учетом контекста: Включена синхронизированная посимвольная локальная история через setUndoRedoEnabled, в то время как глобальный QUndoStack безопасно управляет целостностью состояния всей таблицы.
* [Fix] Поток ввода в элементах управления: Устранена циклическая рекурсия сигналов интерфейса, обеспечив стандартное поведение для клавиш Backspace, Delete и быстрых последовательных нажатий.
* [Fix] Устранение утечки памяти: closeEvent теперь принудительно завершает и очищает поток load_thread, предотвращая скрытые фоновые утечки.
* [Fix] Баг бесконечного цикла изменения размера: Исправлен бесконечный цикл разметки путем блокировки сигналов на заголовке таблицы (table header view), а не на контейнере виджета.
* [Improvement] Цвет полос прокрутки: Скроллбары теперь корректно адаптируются под выбранную тему (темная/теплая/светлая), устраняя стандартную белую полосу в темном режиме.
* [Improvement] Формат TSV для операций с CSV: Разделитель заменен с запятой на табуляцию (\t) для импорта и экспорта CSV. Запятые внутри текстов перевода больше не ломают структуру CSV-файла.
* [Improvement] Производительность Undo/Redo: Введено централизованное управление историей QUndoStack с внутренней блокировкой _bulk_update. Статистика статуса теперь пересчитывается только после завершения массовых операций.
* [Improvement] Оптимизация логики Undo: При клике на ячейку в целевой колонке цикл отслеживания изменений теперь ограничен только ключами с одинаковым базовым именем (через get_base_key). Это значительно повысило производительность на файлах с десятками тысяч строк.
* [Improvement] Оптимизация геометрии окон: Удален избыточный внешний слой иерархии разметки, что убрало лишние внутренние отступы и границы панелей.
* [Improvement] Унификация отображения тем: Исправлены баги глобальных таблиц стилей QSS для безупречной визуальной интеграции во всех активных цветовых схемах интерфейса.
* [Feature] Независимый выбор исходного языка: Добавлен выбор любого языка в качестве базового (референса) вместо жесткой привязки к английскому. Меню выбора языка теперь разделено на два подменю («Исходный язык» и «Целевой язык»). Заголовки столбцов таблицы обновляются динамически.

## 0.3a
* [Fix] Сброс измененных ключей при сохранении: Список отредактированных строк сбрасывается после успешного экспорта в .lcache для корректного отображения фильтров.
* [Fix] Оптимизация истории Undo: Запись в стек истории теперь триггерится только при переключении редактируемой строки, а не при каждом нажатии клавиши. Это предотвращает переполнение стека и потерю полезных правок в текстовых полях.
* [Fix] Атомарное сохранение файлов: Запись в .lcache теперь выполняется через временный файл с последующим переименованием. Это гарантирует сохранность оригинального файла в случае внезапного сбоя программы.
* [Fix] Изоляция истории Undo текстового редактора: Отключена нативная история отмены в QTextEdit во избежание конфликтов с глобальной системой Undo/Redo приложения.
* [Fix] Удаление неиспользуемой переменной: Из кода убрана устаревшая переменная _editing_key_id для очистки кодовой базы.
* [Improvement] Ограничение прямого редактирования ячеек: Ячейки в колонке перевода больше нельзя редактировать прямо в таблице. Все изменения вносятся через нижнее текстовое поле для обеспечения точного отслеживания Undo/Redo.
* [Improvement] Подтверждение импорта CSV: Добавлено явное предупреждение о том, что импорт CSV нельзя отменить через Undo, требующее подтверждения от пользователя.
* [Improvement] Оптимизация импорта CSV: Замена полной пересборки таблицы на простое обновление фильтров после импорта CSV ускорила работу и убрала избыточные обновления интерфейса.
* [Improvement] Рефакторинг update_translation_for_key: Функция больше не изменяет стек Undo/Redo напрямую. Теперь она только обновляет данные и возвращает список изменений, оставляя управление историей вызывающей логике для упрощения кода.
* [Improvement] Кнопки управления окном в стиле macOS: Квадратные кнопки закрытия/сворачивания заменены на круглые «светофоры» (зеленый, желтый, красный). Они расположены на правой стороне (в порядке Windows) и адаптируются к выбранной теме.
* [Improvement] Рамка окна под цвет темы: Рамка окна (2px solid) теперь меняет цвет вместе с активной темой (темная/теплая/светлая) для бесшовной визуальной интеграции.
* [Improvement] Фон заголовка окна: Фон панели заголовка теперь соответствует активной теме, обеспечивая целостный вид во всех цветовых схемах.
* [Improvement] Общая оптимизация интерфейса: Проведен рефакторинг разметки виджетов и фильтров рендеринга для повышения отзывчивости интерфейса под большими нагрузками данных.
* [Feature] Синхронизация переводов: Изменение перевода теперь обновляет все ключи с одинаковым base_key (включая суффиксы _newer, _new, _v3, _v2, _patch). Изменения применяются ко всем связанным строкам сразу, а не только к выбранной.
* [Feature] Групповой Undo/Redo: Действия отмены и повтора теперь работают сразу для всего набора затронутых ключей, а не для одного ключа.

## 0.2a
* [Fix] Исправлена критическая опечатка в update_translation_for_key: Устранен вылет приложения, вызванный несоответствием кортежа и строки при извлечении кодировки.
* [Fix] Исправлена десинхронизация таблицы: Добавлено принудительное обновление flattened_data сразу после любого импорта CSV.
* [Improvement] Оптимизирована палитра темной темы: Повышен контраст текста и снижена нагрузка на глаза во время длительных сессий.
* [Improvement] Сохранение состояния: Состояния всех 4 новых чекбоксов и фильтров теперь сохраняются в settings.ini.
* [Improvement] Адаптация интерфейса: Изменена архитектура разметки для корректного отображения на широкоформатных мониторах.
* [Feature] Мост импорта/экспорта CSV: Добавлена поддержка экспорта и импорта переводов в формате CSV (; в качестве разделителя), совместимом с Excel и LibreOffice. Реализован экспорт для отдельных языков и безопасный импорт с подтверждением.
* [Feature] Расширенные мульти-фильтры: Одиночный чекбокс заменен на четыре опции: Скрыть пустые, Скрыть измененные, Показывать только пустые и Показывать только измененные (для быстрой вычитки).
* [Feature] Счетчик видимых строк: В режиме реального времени под чекбоксами отображается количество видимых и скрытых строк.
* [Feature] Выпадающие меню UI: Все задачи импорта и экспорта (.lcache и CSV) сгруппированы в аккуратные выпадающие меню [Import] и [Export].
